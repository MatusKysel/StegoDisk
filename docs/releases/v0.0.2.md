# StegoDisk v0.0.2

Released September 11, 2026. This release collects the storage fixes, build improvements, and test coverage added since `v0.0.1`.

## Storage and image fixes

- Honor the global permutation selected through the enum-based `Configure()` API. Previously, a configuration-key mismatch silently selected the default global permutation. [#60](https://github.com/MatusKysel/StegoDisk/pull/60)
- Clear previous file exclusions and file-type settings when reconfiguring storage, and apply file-specific encoder overrides during loading and saving. [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Correct capacity estimates, including keyed affine permutations before an encoder has been applied; empty carrier directories report zero estimated capacity. [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Clear the previous virtual storage when opening another directory, including when the new open fails. Reads, writes, and size queries no longer expose the previous store. [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Avoid writing duplicate JFIF and Adobe markers when saving JPEG carriers, and avoid adding those markers when they were absent from the original image. [#57](https://github.com/MatusKysel/StegoDisk/pull/57)
- Address initialization and integer-width issues in memory-buffer moves, JSON scalar values, carrier capacity calculations, and Hamming encoder calculations.

## Library and build changes

- Require **C++17 and CMake 3.25 or newer**. The CMake configuration supports policies through 4.4, and CI uses CMake 4.4.3. Debug builds now retain their normal optimization settings, and project tests support multi-configuration generators. [#59](https://github.com/MatusKysel/StegoDisk/pull/59), [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Replace the custom thread pool with standard parallel algorithms for carrier discovery, loading, and saving. Worker exceptions are propagated to callers. Linux builds require TBB. [#59](https://github.com/MatusKysel/StegoDisk/pull/59), [#61](https://github.com/MatusKysel/StegoDisk/pull/61)
- Include earlier library-export and dependency-linking fixes, and introduce specific exception types for configuration, I/O, and invalid-state errors. See the shared-build limitation below. [#33](https://github.com/MatusKysel/StegoDisk/pull/33)
- Update the bundled dependency revisions to libjpeg-turbo `fe5b6a1c` (reports version 2.0.6) and LodePNG `34628e89` (20200306).
- Refactor the optional FUSE service around per-mount context, translate storage failures into FUSE I/O errors, and discover FUSE through `pkg-config`. FUSE is disabled by default. [#59](https://github.com/MatusKysel/StegoDisk/pull/59)

## Tests and continuous integration

- Expand the project suite to **48 CTest tests**: 36 storage round trips, eight unit-test groups, and four state-regression groups. Coverage includes both encoders, all five permutations, distinct global/local permutations, passwords, wrong passwords, partial payloads, offset writes, reconfiguration, capacity estimates, encoder overrides, and reopening. [#62](https://github.com/MatusKysel/StegoDisk/pull/62), [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Register project tests at the top-level build directory, label them `stegodisk`, and fail test runs when no tests are discovered. [#63](https://github.com/MatusKysel/StegoDisk/pull/63)
- Replace Travis CI and AppVeyor with GitHub Actions for Linux GCC/Clang, macOS Apple Clang, and Windows MSVC; restore CodeQL analysis. The macOS job also builds and tests Debug with Ninja Multi-Config. [#61](https://github.com/MatusKysel/StegoDisk/pull/61), [#63](https://github.com/MatusKysel/StegoDisk/pull/63)

## Upgrading from v0.0.1

- **Existing stores configured through enums:** older versions ignored the requested global permutation and used `FEISTEL_MIX` (`mix_feistel`). To reopen those stores, explicitly select that global permutation and retain the original encoder, local permutation, and password. JSON configurations using `glob_perm` were not affected by this key mismatch.
- **Existing stores with per-file encoder overrides:** older versions ignored these overrides and used the global encoder for every carrier. To reopen those stores, set each file-specific encoder to the global encoder used when the data was saved; retain the permutation settings.
- Rebuild applications against the new library. Some lower-level operations now throw exceptions instead of returning error codes, and the optional `FuseService` API has changed.
- For binaries intended for other machines, configure with `-DOPTIMIZE_FOR_NATIVE=OFF`; native CPU optimization is enabled by default.

## Build and test

Use a recursive Git checkout: GitHub's automatically generated source archives do not include the bundled submodule contents. Install a C++17 toolchain and CMake 3.25 or newer, plus the TBB development package on Linux. For Linux/macOS:

```sh
git clone --branch v0.0.2 --recurse-submodules https://github.com/MatusKysel/StegoDisk.git
cd StegoDisk
cmake -S . -B out -DCMAKE_BUILD_TYPE=Release -DOPTIMIZE_FOR_NATIVE=OFF
cmake --build out --config Release --parallel 4
ctest --test-dir out --build-config Release -L stegodisk --output-on-failure --no-tests=error
```

On Windows, also pass `-DTEST_DIR=C:/Temp/` when configuring, replacing `C:/Temp/` with an existing temporary directory. Use forward slashes and a trailing slash, as in CI, so the generated test header contains a valid path.

No command-line CMake policy override is required. This is a source release; prebuilt binaries are not provided.

## Validation limits

- Release tests and CI use the default static-library build. `BUILD_SHARED=ON` with tests enabled currently fails to link the unit/state tests against internal library symbols. Use `-DBUILD_SHARED=ON -DBUILD_TESTS=OFF` to build the shared library, and a separate default static build to run the project tests.
- The 48 project tests are separate from the bundled JPEG library's tests. The optional `djpeg-static-3x2-float-prog-cmp` JPEG test has a pre-existing checksum mismatch on the local Apple Silicon build, reproduced before the CMake modernization.
- FUSE mounting is not covered by the CI matrix.
